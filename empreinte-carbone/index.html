Empreinte carbone du site

Cet espace pédagogique parle d'éco-conception. On se doit d'en appliquer les principes à soi-même. Voici nos choix et ce qu'on mesure.

Mesure en direct

Le pied de page de chaque page affiche :

  • Grammes de CO₂ émis par visite, calculé via l'API publique de Website Carbon.
  • Pourcentage de pages testées par Website Carbon qui sont plus polluantes que celle-ci.
  • Indication d'hébergement sur énergie renouvelable (si applicable).

Le résultat est mis en cache dans sessionStorage pour éviter un appel API à chaque navigation. Pour le rafraîchir, ferme et rouvre l'onglet.

Principes d'éco-conception appliqués ici

📦 Ressources minimales
  • Aucune image bitmap, icônes en emoji ou SVG inline
  • Polices système uniquement (pas de WOFF custom)
  • CSS et JS maison, sans framework ni dépendance
  • Pas de bundler, pas de tracker
🔋 Sobriété d'exécution
  • Pas de JavaScript bloquant, tous les scripts sont defer
  • Pas d'animation lourde, respect de prefers-reduced-motion
  • Aucun autoplay
  • Cache agressif sur les assets statiques
📡 Réseau
  • Taille de page : inférieure à 200 Ko par page courante
  • HTTPS obligatoire (HSTS activé)
  • Pas de CDN tiers inutile, ressources servies depuis Vercel
♿ Durabilité d'usage
  • Fonctionne sur du vieux matériel et petits écrans (320 px)
  • Fonctionne sur connexion lente (HTML rendu sans JS)
  • Aucun compte requis, aucun téléchargement forcé

Nos limites assumées

  • L'hébergeur Vercel utilise des data centers principalement aux USA et en Europe. Nous n'avons pas le contrôle direct sur leur mix énergétique.
  • L'API Website Carbon est un service tiers (coût réseau marginal, appel mis en cache).
  • Nous n'avons pas encore réalisé d'ACV complète au sens RGESN, c'est un chantier ouvert pour une future itération.
