## Séquence 1 — Inclusion « Un site que je trouve hostile »

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Inclusion — Un site que je trouve hostile |
| **Durée** | 15 min |
| **Heure** | 13h30 |
| **Format** | Plénière / Tour de table |
| **Type** | Inclusion / Brise-glace |

**Objectif pédagogique**
Faire émerger des exemples concrets d'expériences dégradées, ancrer l'accessibilité dans le vécu.

**Instructions animateur**
1. Accueil (2 min) + retour DJ1 : « Qui a coché au moins 5 cases de la checklist depuis hier ? ».
2. Question brise-glace (3 min) : « Un site/app que vous trouvez hostile — sans le nommer si client. ».
3. Tour de table (8 min) : noter au tableau les types d'hostilité (trop petit, pop-ups, lent…).
4. Annoncer le cap (2 min).

**Notes**
Si quelqu'un dit « jamais été gêné·e » : relancer avec « sur téléphone, connexion faible, enfant qui pleure ? ». L'accessibilité concerne tout le monde, ponctuellement ou durablement.

## Séquence 2 — Apport 1 : Les 4 principes POUR

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Apport 1 — Les 4 principes POUR de l'accessibilité |
| **Durée** | 20 min |
| **Heure** | 13h45 |
| **Format** | Plénière / Apport théorique |
| **Type** | Apport de contenu |

**Objectif pédagogique**
Donner un cadre simple et mémorisable : les 4 principes POUR (Perceptible, Opérable, Utilisable/Compréhensible, Robuste) qui structurent WCAG/RGAA.

**Instructions animateur**
1. Pourquoi l'a11y : 20% pop avec handicap, tout le monde ponctuellement, obligation légale RGAA, bon pour SEO et conversion.
2. Les 4 principes POUR avec un exemple concret chacun.
3. Les pièges No-Code : templates par défaut non-accessibles, formulaires, chatbots, images IA.

Faire une démo courte de VoiceOver (Cmd+F5) ou Narrator (Ctrl+Win+Entrée) si possible. Ne pas entrer dans les 106 critères RGAA.

**Notes**
Ne pas entrer dans le détail des critères — garder la vue d'ensemble, savoir où chercher ensuite.

## Séquence 3 — Pratique 1 : Audit accessibilité en binôme

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Pratique 1 — Audit a11y en binôme sur site réel |
| **Durée** | 40 min |
| **Heure** | 14h05 |
| **Format** | Binôme |
| **Type** | Pratique guidée |

**Objectif pédagogique**
Réaliser un vrai audit a11y sur un vrai site avec grille simplifiée et outils gratuits. Apprendre à diagnostiquer.

**Instructions animateur**
1. Constituer 3 binômes (2 min).
2. Attribuer sites (3 min) : service public local / école / site e-commerce connu. Pas de site client.
3. Démo outils (5 min) : axe DevTools, WAVE, lecteur d'écran système, navigation clavier seule.
4. Audit binôme (25 min) : grille d'audit simplifiée, produire 5+ non-conformités (critère, gravité, description, correction).
5. Mise en commun (5 min) : top 3 par binôme.

**Notes**
Les sites publics révèlent souvent des défauts. Insister : « pas des fautes, des chantiers. L'objectif est d'apprendre, pas de pointer du doigt. »

## Séquence 4 — Débrief + Apport 2 : Écoconception, le vrai impact

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Débrief + Écoconception — Le vrai impact |
| **Durée** | 25 min |
| **Heure** | 14h45 |
| **Format** | Plénière |
| **Type** | Débrief + Apport |

**Objectif pédagogique**
Boucler l'audit a11y, puis poser le cadre écoconception : d'où vient l'impact, quels leviers réels.

**Instructions animateur**
1. Débrief audit a11y (8 min) : patterns récurrents, 5-6 critères couvrant 80% des erreurs.
2. Transition (2 min) : du « utilisable » au « utilisable + sobre ».
3. Apport écoconception (15 min) : 4% GES mondiales (ADEME), décomposition fabrication (78%) / data centers / réseaux. 4 leviers : moins de features, moins de données, moins de ressources, durée de vie. Faux amis : énergie verte, compensation, « l'IA résoudra ». Outil : websitecarbon.com.

**Notes**
Insister sur la fabrication (78% de l'impact). Le levier n°1 d'un product builder : faire un produit qui ne force pas au renouvellement matériel.

## Séquence 6 — Pratique 2 : Analyse d'impact sur ton projet

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Pratique 2 — Analyse d'impact éco sur ton projet |
| **Durée** | 60 min |
| **Heure** | 15h25 |
| **Format** | Individuel + coaching |
| **Type** | Pratique guidée |

**Objectif pédagogique**
Mesurer concrètement l'impact d'une fonctionnalité de son projet et identifier 3 optimisations réalistes.

**Instructions animateur**
1. Distribuer checklist éco (3 min).
2. Mesurer impact actuel (15 min) : websitecarbon.com, lister 3-5 appels LLM fréquents + fréquence, 3 plus grosses ressources.
3. Identifier 3 optimisations (30 min) : avec la checklist, actions concrètes + estimation impact.
4. Partage (12 min) : optimisation prioritaire + engagement (semaine ? mois ?).

**Notes**
Beaucoup vont vouloir tout refaire. Ramener au concret : « Une seule action, dans la semaine, mesurable. » Sobriété du petit pas.
