## Séquence 1 — Inclusion « Si j'étais le jury… »

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Inclusion — Si j'étais le jury |
| **Durée** | 15 min |
| **Heure** | 13h30 |
| **Format** | Plénière / Tour de table |
| **Type** | Inclusion / Brise-glace |

**Objectif pédagogique**
Renverser la posture : au lieu d'avoir peur du jury, se mettre à sa place. Comprendre ce qu'un jury cherche permet de mieux préparer ce qu'on présente.

**Instructions animateur**
1. Accueil (2 min) : « On y est. Cette après-midi, on prépare le 13 mai. »
2. Brise-glace (3 min) : « Si tu étais dans le jury, quelle serait LA question que tu poserais à tous les candidats ? »
3. Tour de table (8 min) : noter questions au tableau. Observer : les questions du « jury » sont souvent plus exigeantes que celles imaginées côté candidat.
4. Annoncer le cap (2 min) : 2 simulations, chacun·e passe, plan d'action des 9 jours.

## Séquence 3 — Pratique 1 : Simulation de soutenance (session 1)

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Pratique 1 — Simulation soutenance (2 volontaires) |
| **Durée** | 40 min |
| **Heure** | 14h05 |
| **Format** | Plénière / Simulation |
| **Type** | Pratique / Mise en situation |

**Objectif pédagogique**
Faire passer 2 apprenant·es en conditions réelles, faire émerger par le groupe les points forts et angles morts.

**Instructions animateur**
1. Poser le cadre (3 min) : 2 volontaires × 10 min présentation + 3 min questions.
2. Désigner 2 volontaires (2 min) : les plus prêt·es, mode warm-up.
3. Distribuer grille d'observation aux 4 autres (2 min).
4. Passage 1 (13 min) : présentation + questions.
5. Passage 2 (13 min) : idem.
6. Mini-débrief (7 min) : 1 point fort + 1 point de progrès par passage.

**Notes**
Jouer vraiment le jury : poser 1 question piège, être exigeante-bienveillante. Le confort n'est pas l'objectif.

## Séquence 4 — Débrief + Apport 2 : Les 5 pièges de la soutenance

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Débrief + Les 5 pièges de la soutenance |
| **Durée** | 25 min |
| **Heure** | 14h45 |
| **Format** | Plénière |
| **Type** | Débrief + Apport |

**Objectif pédagogique**
Consolider les apprentissages des simulations, apporter le cadre sur les écueils classiques.

**Instructions animateur**
1. Débrief passages (8 min) : reprendre au tableau ce qui est ressorti.
2. Apport 5 pièges (17 min) : Quoi sans Pourquoi / Cacher les limites / Se perdre en démo tech / Répondre à côté / Oublier l'utilisateur. Pour chaque piège : antidote concret.

**Notes**
Le piège n°2 (cacher les limites) est le plus coûteux : identifier 2-3 limites = signe de maturité pour le jury.

## Séquence 6 — Pratique 2 : Simulation binôme + consolidation

| Champ Modulo | Valeur |
|---|---|
| **Titre** | Pratique 2 — Simulation binôme croisé + consolidation |
| **Durée** | 60 min |
| **Heure** | 15h25 |
| **Format** | Binôme puis individuel |
| **Type** | Pratique / Mise en situation |

**Objectif pédagogique**
Les 4 apprenant·es qui n'ont pas encore passé le font en binôme croisé (plus intime). Les 2 qui ont déjà passé consolident leurs livrables.

**Instructions animateur**
1. Constituer 2 binômes croisés (3 min) — les 4 restants.
2. Simulation 1er passage (15 min) : 10 min présentation + 5 min feedback dans chaque binôme. Pendant ce temps, les 2 de la session 1 avancent leurs livrables.
3. Rotation — 2e passage binôme (15 min) : même format inversé.
4. Consolidation individuelle (27 min) : chacun·e utilise le Kit prépa éval, identifie les livrables manquants, démarre les templates, prépare 3 questions pour Anaïs.

**Notes**
Animatrice circule entre binômes pendant les passages puis coache ceux qui consolident.

| **Type** | Consolidation / Plan d'action |

**Objectif pédagogique**
Construire un rétro-planning réaliste pour les 9 jours. Sortir avec un plan, pas une intention.

**Instructions animateur**
