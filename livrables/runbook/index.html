Template Runbook d'incident

Fiche à remplir avant l'incident. Une fiche par type de panne probable. Copie ce template dans ton wiki projet (Notion, README), duplique par scénario, teste au moins une fois par trimestre.

💡 Comment utiliser

Duplique ce template une fois par type d'incident probable (ex : panne Make, Airtable corrompu, clés API fuitées, utilisateur bloqué). Teste au moins une fois par trimestre en simulant l'incident et en suivant le runbook : si une étape ne marche pas, corrige à chaud.

📄 Template Runbook

  • Titre de l'incident : [ex : « Le scénario Make ne s'exécute plus »]
  • Dernière mise à jour : [date], Par : [nom]
  • Dernière fois testé : [date]

🔎 Comment on sait qu'on est dans ce cas ?

Symptômes observables, dans l'ordre de probabilité :

  • [Symptôme 1, ex : « Les emails automatiques ne partent plus depuis ce matin »]
  • [Symptôme 2]
  • [Symptôme 3]

🩺 Diagnostic (dans l'ordre)

  1. [Action de diagnostic 1, ex : « Aller sur status.make.com, vérifier si Make a un incident », critère de réussite : réponse observable]
  2. [Action de diagnostic 2, ex : « Aller dans le dashboard Make, onglet Scenarios, vérifier si le scénario est ON et son dernier run »]
  3. [Action de diagnostic 3, ex : « Regarder les logs du dernier run pour voir le message d'erreur »]

🛠️ Actions correctives (par ordre d'effort)

  1. [Action 1, la plus simple, la plus rapide]
  2. [Action 2, si la 1 ne marche pas]
  3. [Action 3, rollback, plan B, dernier recours]

📞 Qui alerter et quand

  • Si l'action 1 résout : [qui prévenir éventuellement, ex : message Slack]
  • Si on passe à l'action 2-3 : [personne à alerter, canal]
  • Si aucune action ne résout (30 min sans solution) : [personne de dernier recours, téléphone]

🔁 Après l'incident

  • Noter l'incident dans le registre (date, cause, durée, action qui a résolu).
  • Si l'incident était nouveau : mettre à jour ce runbook.
  • Si l'incident est récurrent : prévoir une vraie correction structurelle (pas juste un patch).
  • Si impact utilisateur : préparer la communication (ce qu'on dit, quand, à qui).
