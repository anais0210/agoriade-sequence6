Template Mini-AIPD

Version simplifiée de l'AIPD officielle CNIL, adaptée à un projet No-Code/IA en phase de MVP. À remplir en 30 à 45 minutes pour un traitement à la fois. Duplique le fichier si tu as plusieurs traitements à analyser.

⬇️ Télécharger (Markdown)
💡 Comment utiliser

Télécharge la version Markdown pour l'ouvrir dans ton éditeur préféré (Notion, Obsidian, VS Code, Typora…), ou copie-colle chaque bloc dans un doc à toi (Word, Google Doc). Remplis pour un traitement à la fois.

📦 Bloc 1, Description du traitement

  • Nom du traitement : [ex : « Pré-qualification automatique des candidatures »]
  • Finalité(s) : [pourquoi je traite, ex : évaluer l'adéquation d'un profil au poste]
  • Responsable : [nom + rôle]
  • Personnes concernées : [ex : candidat·es externes]
  • Catégories de données : [liste précise : nom, email, CV, réponses au questionnaire, score]
  • Données sensibles : [oui / non, si oui, lesquelles et sur quel fondement]
  • Flux de données : [schéma ou description : source → traitements → stockage → destinataires]
  • Sous-traitants : [liste : outil + pays + DPA signé oui/non]
  • Durée de conservation : [par catégorie de donnée]

⚖️ Bloc 2, Nécessité et proportionnalité

  • Base légale retenue : [consentement / contrat / intérêt légitime / etc.], Justification : [pourquoi celle-ci]
  • Données strictement nécessaires : [oui / non, si non, quoi enlever ?]
  • Information des personnes : [comment, quand, sur quoi]
  • Droits : [comment une personne exerce ses droits, procédure concrète]
  • Sous-traitants conformes : [DPA signés ? Transferts hors UE encadrés ?]

⚠️ Bloc 3, Identification des risques

Pour chaque scénario ci-dessous, évaluer : Impact (faible/modéré/élevé) × Probabilité (faible/modérée/élevée).

  • Scénario 1, Accès illégitime : qu'est-ce qui se passe si les données fuitent ? [impact × probabilité] [sources du risque]
  • Scénario 2, Modification non désirée : si les données sont modifiées par erreur ou malveillance ? [impact × probabilité]
  • Scénario 3, Disparition : si les données sont perdues ? [impact × probabilité]

🛡️ Bloc 4, Mesures de traitement des risques

Pour chaque risque identifié, préciser les mesures de prévention, détection et réaction.

RisquePréventionDétectionRéaction
Accès illégitime[ex : 2FA, droits restreints][ex : logs d'accès][ex : révocation, notif CNIL si nécessaire]
Modification[ex : historique, validation][ex : alertes][ex : rollback backup]
Disparition[ex : sauvegarde auto][ex : monitoring][ex : restauration + comm]
✅ Conclusion

Les risques résiduels sont-ils acceptables au regard de la finalité ? [oui / non / à renforcer par…]
